Tentang SolarCast

Sistem sederhana untuk memahami potensi daya panel surya

SolarCast menghubungkan data kondisi lingkungan dengan model pembelajaran mesin untuk menghasilkan perkiraan daya AC panel surya. Sistem dirancang sebagai media pembelajaran dan demonstrasi penerapan perangkat lunak berbasis web.

Peramalan Daya

Sistem menggunakan tiga parameter utama, yaitu suhu lingkungan, suhu modul panel, dan iradiasi matahari. Ketiga parameter tersebut diberikan kepada model Random Forest untuk menghasilkan perkiraan daya AC dalam satuan Watt.

Pemanfaatan Energi Surya

SolarCast membantu memberikan gambaran hubungan antara kondisi lingkungan dan pembangkitan daya panel surya. Pengembangan sistem ini juga berkaitan dengan pemanfaatan teknologi digital untuk mendukung pemahaman mengenai energi bersih dan terjangkau.

Alur Sistem

Bagaimana SolarCast bekerja?

SolarCast melakukan proses prediksi melalui beberapa tahap, mulai dari memasukkan kondisi lingkungan sampai menampilkan perkiraan daya.

01

Input Kondisi

Pengguna memasukkan suhu lingkungan, suhu modul panel, dan nilai iradiasi matahari.

02

Data Diproses

Sistem menyusun ketiga nilai tersebut menjadi data input dengan format yang sesuai dengan fitur model.

03

Random Forest

Model Random Forest yang telah dilatih menggunakan data pembangkitan panel memproses nilai input tersebut.

04

Hasil Prediksi

Sistem menampilkan perkiraan daya AC dalam satuan Watt beserta keterangan kondisi pembangkitan.

Apa arti MAE dan RMSE?

MAE atau Mean Absolute Error menunjukkan rata-rata selisih absolut antara nilai aktual dan hasil prediksi. RMSE atau Root Mean Squared Error memberikan penalti lebih besar terhadap kesalahan yang lebih besar. Semakin kecil nilai keduanya, semakin kecil kesalahan prediksi pada data pengujian.

Apa arti R²?

R² atau koefisien determinasi menunjukkan seberapa baik model menjelaskan variasi nilai daya pada data pengujian. Nilai yang semakin mendekati 1 menunjukkan kemampuan penjelasan model yang semakin tinggi pada data yang diuji.
